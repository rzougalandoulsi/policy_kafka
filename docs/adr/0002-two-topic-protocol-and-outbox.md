# ADR 0002: Two-topic protocol with typed Avro envelopes, outbox/inbox
`requests.manifest` (commands) and `response.manifest` (events) carry explicit Avro envelopes with command/event enums and full correlation metadata. Governance writes through a transactional outbox and reads through an idempotent inbox; the Orchestrator is required to release a plan at most once (EOS v2 with a co-located plan store is the recommended implementation). Alternatives rejected: extra topics per message type (contract forbids), JSON payloads (no schema evolution), direct dual writes (inconsistency).
